# 密码管理器（PHP + MySQL）

一个轻量、可自部署的密码管理后台：**无前台展示页，访问即进入登录界面**；登录后按「密码库」组织账号，每个账号除账号/密码外，支持任意多条可修改字段与图片；支持多管理员、密码加密存储与深度界面自定义。

## 功能清单

- **入口即登录**：`index.php` 未登录自动跳转登录页，无任何前台展示页。
- **管理器账户页**（超级管理员可见）：查看、添加、重置密码、调整角色（超级管理员/普通管理器）、删除管理器账户。
- **密码库管理**：
  - 添加密码库（可上传密码库图片）。
  - 编辑密码库：修改名称、**更换密码库图片**、移除图片、删除密码库。
  - 密码库列表：卡片式展示，含封面图与账号数量。
- **账号管理**：
  - 密码库内添加账号：账号名称、账号、密码，以及**多条可修改字段**（前端动态添加、后端批量入库）；账号支持上传/更换/移除图片。
  - 编辑/删除账号（删除时自动清理图片文件）。
  - 账号卡片中，可修改字段与账号图片收纳在「**其他信息**」折叠区内，默认收起、可点击展开；账号图片以缩略图展示，**点击后在灯箱中放大预览**（不再作为头像）。
  - 字段值为链接（`http://`/`https://` 开头）时自动变为可点击链接，点击**新窗口打开**。
  - 密码加密存储（AES-256-CBC），默认打码显示，点击「显示」经接口取回明文。
- **系统设置**（超级管理员）：主题模式（浅色/深色）、主题色、页面背景颜色/背景图、登录页自定义（标题/副标题/Logo/登录背景）、**顶部导航透明度**与**账号卡片透明度**（毛玻璃，0–100% 可调）。
- **登录页**：背景图自动拉伸铺满并居中；整页**锁死在一屏内，不上下滚动**，内容超高时仅在登录卡片内滚动。
- **安全措施**：PDO 预处理防注入、密码 `password_hash` 加盐、CSRF 校验、上传类型白名单 + 内容校验（`getimagesize`）、`config/includes` 与上传目录禁 Web 访问、外部链接 `rel="noopener noreferrer"` 防反客攻击。
- **健壮性**：`settings` 表缺失时**自动建表**；`credentials` 表缺 `image` 列时**自动迁移**——旧库升级无需手动改表。
- **响应式布局**：适配手机/平板/桌面，小屏下导航、表格、表单自动换行与横向滚动。

## 部署步骤（宝塔 / XAMPP）

要求：PHP ≥ 7.4（建议 8.x），扩展 `pdo_mysql`、`openssl`、`gd`（或 `fileinfo`）、`mbstring`。

### 方式一：一键导入（推荐，适用于 mima 库已建好或未建表）

1. 把整个 `password-manager` 文件夹上传到站点根目录（如 `/www/wwwroot/mima`）。
2. 在 phpMyAdmin **左侧选中 `mima` 数据库**，顶部「导入」选择 **`mima_import.sql`** 执行。该文件会完成全部建表 + 写入默认管理员与系统设置默认项，且不包含 `CREATE DATABASE`，不会触发 #1044 无权建库的报错。
   - 若库还未创建：先在 phpMyAdmin 新建一个数据库（如 `mima`，utf8mb4），再按上面导入。
   - 也可命令行：`mysql -u mima -p mima < mima_import.sql`
3. 打开 `config/config.php`，按环境填写：
   - `DB_NAME`/`DB_USER`：`mima`；`DB_PASS`：填该库的真实密码（`DB_HOST` 一般 `127.0.0.1`）。
   - `ENCRYPTION_KEY`：改成你自己的随机字符串（用于加密账号密码，务必保密，改动会导致已存密码无法解密）。
   - 若部署在子目录（如 `/mima`），把 `BASE_URL` 改为 `/mima`；根目录部署留空 `''`。
4. 浏览器打开站点根地址，自动进入登录页。默认账户：`admin` / `admin123`（超级管理员）。

### 方式二：传统两段式

- 全新库：导入 `database.sql`（自动建库建表 + 默认管理员）；若账户无 `CREATE DATABASE` 权限（#1044），改用 `database_no_create.sql`（需先选中库）。
- 表已建好、只需补数据：导入 `seed_data.sql`（仅默认管理员 + 设置默认项）。

> 提示：`assets/uploads` 目录需要可写权限以保存密码库/账号图片。宝塔若目录只读，请 `chown -R www:www` 并给该目录写权限（目录内已放禁执行的 `.htaccess`，无脚本风险）。

## 登录后

- 到「管理器账户」页**立即修改默认密码**，并可添加其他管理器账户。
- 到「添加密码库」创建密码库，密码库内添加账号、可修改字段与账号图片。
- 到「系统设置」调整主题、背景、登录页、顶部导航透明度与账号卡片透明度。

## 升级旧部署（从更早版本）

若旧库 `mima` 中还没有 `settings` 表 / `credentials` 缺 `image` 列：

1. **无需手动改表**：上传新版源码后，代码会自动建 `settings` 表、自动为 `credentials` 补 `image` 列。
2. 仅当你想用脚本补设置默认项时，可导入 `settings_table.sql`（只新增设置表并写入默认项，不影响已有数据）。
3. 上传本版全部源码文件，用超级管理员登录进入「系统设置」即可看到主题、背景、登录页与透明度设置。

## 说明与限制

- 本工程为**完整可部署的源码**。开发机未安装 PHP/MySQL，交付前以静态方式核验（PHP 标签结构、文案一致性），未做真实运行验证；请部署到支持 PHP + MySQL 的环境后运行，如有报错请贴出环境信息。
- 账号密码以 `ENCRYPTION_KEY` 加密后入库；请妥善保管密钥并设置强登录密码。
- 密码库/账号图片仅保存文件路径，删除对应记录或移除图片时会同步清理文件。
- 普通管理器只能管理自己的密码库；管理器账户页仅超级管理员可见。
